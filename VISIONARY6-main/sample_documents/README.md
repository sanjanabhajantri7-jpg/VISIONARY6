# Safe specimen inputs

VeriScan does not ship or generate realistic Aadhaar, PAN, driving licence, or passport imagery. Use the in-app `Load SPECIMEN document` action for a fictional PNG with a placeholder portrait, `TEST-0000-0000`, a large SPECIMEN label, and a fictional issuer.

For OCR/field-extraction experiments, users may place non-Indian mock identity documents from the MIDV-500 or MIDV-2020 dataset in this folder. Obtain those files separately and follow their distribution terms; this project does not download them automatically.
